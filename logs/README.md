# Task Summary Logs

Create one concise Markdown summary for each implemented task, named
`YYYY-MM-DD-short-task-name.md`.

Each summary should record:

- approved scope and relevant owner decisions;
- important implementation assumptions;
- files or behavior changed;
- verification commands and results;
- failures, limitations, or deliberately deferred work.

These logs are factual engineering records. Broader lessons and personal analysis
belong in `docs/Reflections.md`.
